# Step 7 — The Claude Project coach (20 min)

This is Vern's other half: a Claude Project where the job seeker preps
interviews, tailors CVs, and drafts outreach — fed by the newsletter's
"Start here" prompts.

In the JOB SEEKER's claude.ai account (needs Pro/Max):

1. **Projects → New project** → name it "Next Chapter HQ".
2. Open **Set project instructions** → paste the full text of
   `claude-project/instructions.md` (your customized version from Step 6).
3. Upload to **Project knowledge**: the files in
   `claude-project/knowledge/` (customized, WITH real numbers — Projects
   are private) plus the real resume.
4. Test 1: say **"Hi Vern."** — he should know exactly who he's coaching.
   If he acts generic, the instructions paste didn't take.
5. Test 2: open the web edition, expand any good job's **"Start here"**
   prompt, copy it, paste it into the Project. You should get a blunt
   verdict-first fit check, then application drafting.

The daily loop this creates: email at the chosen hour → open full
edition → tap a prompt → paste into the Project → Vern does the heavy
lifting.

(optional) or you're done with the core.
