# Step 1 — Accounts you need (15 min)

1. **GitHub** (free): [github.com](https://github.com) → Sign up. Hosts
   the code, runs the nightly automation, serves the web edition.
2. **Anthropic API key** (pay-per-use): [console.anthropic.com](https://console.anthropic.com)
   → sign up → **Billing** (add a payment method) → **API Keys** → Create
   Key. Copy it somewhere safe for Step 3. Nightly scoring costs roughly
   $10–20/month on the default model (or ~$2–4 on Sonnet — Step 3 shows
   the switch).
3. **A Gmail account to SEND from** (free): the operator's own Gmail is
   fine. You'll mint an "app password" for it in Step 3.
4. **Claude Pro or Max for the job seeker** ([claude.ai](https://claude.ai)):
   powers the career-coach Project in Step 7. Not needed until then.
