# Step 2 — Copy the template (10 min)

1. On the template repository's page, click the green **Use this
   template** button → **Create a new repository**.
2. Name it anything (e.g. `next-chapter-mine`).
3. **Public or private?** Public = the free web edition works immediately
   (GitHub Pages is free on public repos). Private = you need GitHub Pro
   ($4/month) for Pages. Most choose **public**: the design keeps every
   personal detail out of committed files — see
   [Step 10](10-privacy-and-troubleshooting.md) before you commit anything
   yourself.
4. On YOUR new repo: **Settings → Actions → General** → "Allow all
   actions" selected, and under **Workflow permissions** choose **Read and
   write permissions** → Save. (Without this, the nightly run can't save
   its memory of which jobs it already showed.)
